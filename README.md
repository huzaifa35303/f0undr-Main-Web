# f0undr — Creative Production, Deep-Tech & AI Systems Agency

Official website for **f0undr** — a hybrid creative studio, deep-tech engineering lab, and autonomous AI workforce agency.

## 🚀 Capabilities

- **Commercial Ads & Key Visual Posters:** Cinema-grade product commercials, 3D motion graphics, and high-impact poster suites.
- **Autonomous AI Agents & Workflows:** Pre-trained, multi-agent swarms with MCP tooling and deterministic guardrails.
- **Cross-Platform Software:** Desktop applications (Windows/macOS), iOS & Android apps, and full-stack Next.js web platforms.
- **Game Development:** Real-time simulations, shader programming, and interactive engines.
- **Reverse Engineering & Security (REA):** Binary analysis, memory profiling, and protocol verification.

## 🛠 Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Styling:** Tailwind CSS with custom `:root` design tokens
- **Icons & UI:** Lucide React
- **Live AI Platform:** [ai.f0undrteam.site](https://ai.f0undrteam.site/)
- **Contact:** [huzaifa.f0undr@gmail.com](mailto:huzaifa.f0undr@gmail.com)

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
npm start
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
